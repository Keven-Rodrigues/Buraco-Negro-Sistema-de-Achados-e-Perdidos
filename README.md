# Buraco-Negro-Sistema-de-Achados-e-Perdidos
Aplicativo de achados e perdidos desenvolvido em C# com .NET MAUI, utilizando MVVM, SQLite e Singleton, com cadastro de usuários, gerenciamento de objetos e histórico de seleções.
🌌 Buraco Negro

Sistema de achados e perdidos desenvolvido em C# e .NET MAUI, como projeto acadêmico.

📌 Sobre o projeto

O Buraco Negro é um aplicativo que permite cadastrar, consultar e gerenciar objetos perdidos ou encontrados, facilitando o registro de informações e o acompanhamento dos objetos de interesse.

⚙️ Tecnologias utilizadas
C#
.NET MAUI
XAML
SQLite
MVVM
Singleton
✨ Funcionalidades
Cadastro e autenticação de usuários.
Acesso diferenciado para administradores e clientes.
Cadastro, edição, exclusão e consulta de objetos.
Seleção de objetos de interesse.
Histórico de seleções com data e hora.
Armazenamento persistente em SQLite.
🎯 Objetivo

Aplicar os conhecimentos de desenvolvimento de aplicativos móveis, organização de código com MVVM e persistência de dados com SQLite.

👨‍💻 Status

Projeto acadêmico em desenvolvimento.
